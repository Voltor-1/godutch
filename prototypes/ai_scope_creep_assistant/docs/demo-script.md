# Demo Script — AI Scope Creep Assistant (1-day prototype)

1. Start app:
   - `cd prototypes/ai_scope_creep_assistant`
   - `npm run dev`
2. Open `http://localhost:8787`
3. Keep default project: `Website Redesign + CMS Migration`
4. Paste baseline scope and sample thread (defaults preloaded)
5. Click **Analyze**
6. Review labels (`in_scope`, `unclear`, `likely_out_of_scope`)
7. Adjust accepted items via checkboxes
8. Click **Generate draft from accepted items**
9. Click **Download Markdown**
10. Show exported file in `exports/change-order-draft.md`
